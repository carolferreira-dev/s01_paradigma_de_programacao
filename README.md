## 📌 Sobre a disciplina

A disciplina estuda a evolução histórica das linguagens de programação, a sintaxe e a semântica, e o desenvolvimento de aplicações práticas nos paradigmas imperativo, orientado a objetos, funcional e lógico, usando uma linguagem diferente a cada relatório.

## 💡 Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/carolferreira-dev/s01_paradigma_de_programacao.git
   ```

2. Entre na pasta desejada:
   ```bash
   cd s01_paradigma_de_programacao/relatorio5
   ```

3. Compile e execute conforme a linguagem:

   | Linguagem | Comando |
   |---|---|
   | C++ | `g++ exercicio1_equipes.cpp -o executavel` e depois `./executavel` |
   | Go | `go run exercicio1_codigo_rastreio.go` |
   | Rust | `rustc Ex_02.rs` e depois `./Ex_02` |
   | Lua | `lua exercicio1_tabela.lua` |
   | C# | `dotnet run` (dentro de um projeto) ou `csc Exercicio01.cs` |
   | Python | `python exercicio01.py` |
   | Ruby | `ruby Ex_01.rb` |
